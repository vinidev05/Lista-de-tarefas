# 📝 Lista de Tarefas

Aplicação de lista de tarefas desenvolvida com **React 18**, utilizando **Recoil** para gerenciamento de estado global.

---

## 🚀 Tecnologias utilizadas

- React 18
- Recoil
- Vite
- CSS3

---

## 🎯 Funcionalidades

- ✅ Adicionar tarefas
- ✅ Marcar como concluída
- ✅ Filtrar tarefas (Todas | Pendentes | Concluídas)
- ✅ Remover tarefas
- ✅ Interface estilizada com CSS
